# 42.space Fast 刷分指南

公开版：只包含通用提示词和操作方式，不含钱包地址、登录邮箱、邀请码或 PIN。

## 怎么用

1. 在 Grok Bot 里准备好 `clawby-data` 这套 42.space 脚本。脚本目录一般是 `/home/box/agent-data/workflows/clawby-data/script/42space/`。
2. 把 [`42space-刷分提示词.md`](./42space-刷分提示词.md) 整段贴进刷分 Bot 的系统提示词。
3. 登录时自行填入你的 42 邀请码、邮箱和 PIN。这些只留在私有环境，不要提交回这个仓库。

## 仓库里有什么

- `42space-刷分提示词.md`：可直接粘贴的完整系统提示词，覆盖从零开户、Fast 规则、官方 RPC 轮换、supervisor 能力、磨损计算、资金估算、用户指令理解和收尾清单。

如果以后要把带账户细节的版本存起来，请放到私有仓库，不要把真实地址、邮箱或邀请码写进本仓库。
